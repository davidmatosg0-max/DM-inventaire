# Scripts de Voix Off - Vague 2

## Objectif

Ce document fournit les scripts de locution mot a mot pour la deuxieme vague de mini tutoriels video:

1. Liaison
2. Rapports
3. Achats
4. Dechets & compostage

Ces scripts prolongent le premier lot et gardent le meme niveau de clarte, de duree et de ton.

---

## Regles de Lecture

- Lire avec un rythme calme et stable.
- Laisser une courte respiration entre deux actions visibles.
- Garder exactement les mots des fonctions si l'interface affiche ces libelles.
- Si un ecran charge, couper ce temps au montage.

---

## 1. Liaison

### Duree cible
60 secondes

### Incrustation d'ouverture
Liaison
Envoyer un email groupe avec filtres

### Script mot a mot

00:00 - 00:06
"Le module Liaison permet de communiquer rapidement avec les organismes a partir d'une liste ciblee."

00:06 - 00:14
"Ouvrez l'envoi d'email groupe pour preparer une communication collective sans sortir du module."

00:14 - 00:23
"Commencez par filtrer les organismes. Vous pouvez maintenant cibler par jour de rendez-vous et par classification."

00:23 - 00:32
"Une fois les filtres appliques, selectionnez uniquement la liste visible. Cela evite les erreurs de destinataires."

00:32 - 00:41
"Renseignez ensuite l'objet et le message, puis verifiez une derniere fois le groupe avant l'envoi."

00:41 - 00:50
"Si vous travaillez depuis la gestion des demandes, un bouton de retour vous ramene directement a Liaison sans casser le flux."

00:50 - 01:00
"Le bon reflexe est donc simple: filtrer, selectionner, relire, puis envoyer."

### Texte ecran recommande
- Email groupe
- Filtre jour de rendez-vous
- Filtre classification
- Selection visible
- Retour a Liaison

### Derniere phrase a afficher
Reflexe: filtrez avant de selectionner le groupe.

## 2. Rapports

### Duree cible
60 secondes

### Incrustation d'ouverture
Rapports
Lire les chiffres utiles et exporter

### Script mot a mot

00:00 - 00:06
"Le module Rapports regroupe les indicateurs utiles pour analyser les entrees, les sorties et l'activite globale."

00:06 - 00:14
"Choisissez d'abord la bonne periode. C'est la base de toute lecture fiable."

00:14 - 00:23
"Ouvrez ensuite l'onglet Operations. Cet ecran consolide les chiffres de flux et les valeurs du mois ou de la periode choisie."

00:23 - 00:33
"La valeur entrante est maintenant calculee correctement, meme lorsque certaines anciennes entrees n'avaient pas de montant enregistre."

00:33 - 00:42
"Lisez les graphiques, comparez les volumes et reperez les variations utiles pour la decision."

00:42 - 00:51
"Quand l'analyse est terminee, utilisez l'export pour partager un rapport propre avec l'equipe ou la coordination."

00:51 - 01:00
"Le bon reflexe est de verifier la periode, puis la valeur entrante, avant toute interpretation."

### Texte ecran recommande
- Periode
- Onglet Operations
- Valeur entrante
- Graphiques
- Export

### Derniere phrase a afficher
Reflexe: verifier la periode avant de lire les chiffres.

## 3. Achats

### Duree cible
75 secondes

### Incrustation d'ouverture
Achats
Creer et faire valider un bon d'achat

### Script mot a mot

00:00 - 00:07
"Le module Achats pilote les bons d'achat, les programmes budgetaires et les autorisations internes."

00:07 - 00:16
"Commencez par le tableau de bord. Il montre le volume engage, les demandes en attente et les receptions finalisees."

00:16 - 00:25
"Pour creer un nouveau bon, ouvrez la gestion des bons d'achat puis lancez la creation."

00:25 - 00:35
"Associez un fournisseur, un programme d'achat, le montant, les lignes utiles et la date souhaitee."

00:35 - 00:44
"Quand le bon est pret, soumettez-le au circuit d'autorisation. Les validations internes apparaissent ensuite dans la file d'attente."

00:44 - 00:54
"Une fois approuve, le bon peut etre previsualise, exporte en PDF, puis marque commande ou recu selon son avancement reel."

00:54 - 01:05
"Le module permet aussi de suivre les fournisseurs, les programmes d'achat et les regles d'autorisation sans quitter l'espace Achats."

01:05 - 01:15
"Le bon reflexe est de rattacher chaque bon a un programme pour garder une vision claire du budget et des validations."

### Texte ecran recommande
- Tableau de bord achats
- Nouveau bon
- Programme d'achat
- Autorisations
- PDF

### Derniere phrase a afficher
Reflexe: rattacher chaque bon a un programme.

## 4. Dechets & compostage

### Duree cible
50 secondes

### Incrustation d'ouverture
Dechets & compostage
Tracer les volumes et sortir un rapport

### Script mot a mot

00:00 - 00:06
"Le module Dechets et compostage sert a suivre les volumes sortants en kilogrammes de facon simple et lisible."

00:06 - 00:14
"Dans l'onglet Gestion par kilo, saisissez la date, le type, la categorie, le poids et les notes du registre."

00:14 - 00:23
"Chaque enregistrement peut ensuite etre modifie, duplique ou supprime selon le besoin operationnel."

00:23 - 00:33
"Passez ensuite a l'onglet Rapport par dates pour analyser une periode complete avec le volume total et les categories dominantes."

00:33 - 00:42
"Le rapport peut etre exporte en Excel ou en PDF pour les bilans mensuels ou le suivi interne."

00:42 - 00:50
"Le bon reflexe est de garder des types et des categories coherents pour obtenir des rapports vraiment exploitables."

### Texte ecran recommande
- Gestion par kg
- Type
- Categorie
- Rapport par dates
- Export Excel / PDF

### Derniere phrase a afficher
Reflexe: normaliser les categories pour fiabiliser les rapports.

---

## Conseils de Post-Production

- Conservez la meme musique d'ouverture que dans la premiere vague.
- Affichez les titres d'etape en surimpression pendant 2 a 3 secondes.
- Pour Liaison et Achats, zoomez legerement sur les actions de validation.
- Pour Rapports, laissez le temps de lire les chiffres avant de passer a l'export.
