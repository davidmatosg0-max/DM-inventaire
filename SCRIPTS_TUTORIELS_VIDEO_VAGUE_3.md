# Scripts de Voix Off - Vague 3

## Objectif

Ce document rassemble la troisieme vague de scripts mot a mot pour les mini tutoriels video suivants:

1. Organismes
2. Transport
3. Etiquettes
4. Configuration

Le ton, le format et la duree restent alignes avec les vagues precedentes.

---

## Regles de Lecture

- Lire avec un ton direct, calme et professionnel.
- Marquer une pause breve entre deux ecrans ou deux clics importants.
- Garder les noms des boutons et onglets tels qu'ils apparaissent a l'ecran.
- Si un parcours prend plus de temps en reel, raccourcir au montage plutot que d'accelerer la voix.

---

## 1. Organismes

### Duree cible
60 secondes

### Incrustation d'ouverture
Organismes
Mettre a jour une fiche partenaire

### Script mot a mot

00:00 - 00:06
"Le module Organismes centralise les informations des partenaires beneficiaires et de leurs contacts."

00:06 - 00:14
"Commencez par rechercher l'organisme concerne pour eviter d'ouvrir ou de modifier la mauvaise fiche."

00:14 - 00:23
"Ouvrez ensuite la fiche et verifiez les coordonnees, la classification, les contacts et les informations de capacite."

00:23 - 00:32
"Si un changement est necessaire, corrigez directement les champs utiles sans sortir du module."

00:32 - 00:41
"Enregistrez ensuite la fiche pour que les autres modules, comme Commandes ou Liaison, utilisent les bonnes informations."

00:41 - 00:52
"Cette mise a jour est importante, car une fiche organisme obsolete peut entrainer une mauvaise livraison ou une mauvaise communication."

00:52 - 01:00
"Le bon reflexe est donc de verifier la fiche avant toute commande, tout email groupe ou tout changement de planning."

### Texte ecran recommande
- Recherche organisme
- Fiche partenaire
- Coordonnees
- Classification
- Enregistrer

### Derniere phrase a afficher
Reflexe: verifier la fiche avant chaque action importante.

## 2. Transport

### Duree cible
50 secondes

### Incrustation d'ouverture
Transport
Programmer une livraison

### Script mot a mot

00:00 - 00:06
"Le module Transport sert a organiser les livraisons et a suivre leur progression."

00:06 - 00:14
"Choisissez d'abord la commande a livrer. Le transport doit toujours partir d'une demande deja preparee ou validee."

00:14 - 00:22
"Affectez ensuite la date, les informations logistiques et les notes utiles pour la tournee."

00:22 - 00:31
"Verifiez le statut de la livraison pour savoir si elle est programmee, en cours ou deja finalisee."

00:31 - 00:40
"Cet ecran vous aide a garder une trace claire du flux de distribution sans sortir du cadre operationnel."

00:40 - 00:50
"Le bon reflexe est de valider la commande d'abord, puis de planifier son transport dans un second temps."

### Texte ecran recommande
- Choisir une commande
- Date de livraison
- Notes logistiques
- Statut

### Derniere phrase a afficher
Reflexe: valider d'abord, planifier ensuite.

## 3. Etiquettes

### Duree cible
45 secondes

### Incrustation d'ouverture
Etiquettes
Imprimer ou reimprimer rapidement

### Script mot a mot

00:00 - 00:05
"Le module Etiquettes permet de preparer les reperes physiques des produits en stock."

00:05 - 00:13
"Selectionnez d'abord le bon produit ou une entree recente pour eviter toute erreur d'impression."

00:13 - 00:21
"Verifiez ensuite l'aperçu. Prenez quelques secondes pour controler le lot, la temperature et les informations affichees."

00:21 - 00:30
"Quand tout est correct, lancez l'impression. Si besoin, la meme etiquette peut etre reimprimee sans ressaisie complete."

00:30 - 00:38
"Cette etape garantit une identification claire du produit dans l'entrepot et dans les operations quotidiennes."

00:38 - 00:45
"Le bon reflexe est de verifier avant impression, puis de reimprimer seulement si la fiche est conforme."

### Texte ecran recommande
- Produit
- Apercu
- Lot
- Temperature
- Imprimer

### Derniere phrase a afficher
Reflexe: controler l'aperçu avant chaque impression.

## 4. Configuration

### Duree cible
55 secondes

### Incrustation d'ouverture
Configuration
Ajuster un parametre cle du systeme

### Script mot a mot

00:00 - 00:06
"Le module Configuration regroupe les reglages qui influencent le fonctionnement global de l'application."

00:06 - 00:15
"Pour une intervention propre, commencez par ouvrir uniquement la section qui correspond a votre besoin: categories, options ou parametres."

00:15 - 00:24
"Modifiez ensuite un exemple simple, en prenant soin de bien relire la valeur ou le libelle avant de sauvegarder."

00:24 - 00:34
"Dans ce module, une petite modification peut avoir un effet sur plusieurs ecrans. Il vaut donc mieux avancer avec une logique tres ciblee."

00:34 - 00:45
"Une fois la sauvegarde faite, revenez a l'ecran concerne pour verifier que le comportement attendu est bien applique."

00:45 - 00:55
"Le bon reflexe est de faire des changements courts, controles, puis de valider le resultat tout de suite dans le module impacte."

### Texte ecran recommande
- Ouvrir une section
- Modifier
- Sauvegarder
- Verifier dans le module impacte

### Derniere phrase a afficher
Reflexe: modifier peu, verifier tout de suite.

---

## Conseils de Post-Production

- Utiliser la meme voix et le meme niveau sonore que pour les vagues precedentes.
- Afficher les noms des modules en debut de video avec le meme style visuel.
- Pour Configuration, ajouter un carton visuel discret indiquant que les changements ont un impact transversal.
- Pour Etiquettes, laisser le temps de lire l'aperçu avant de couper.
