# Scripts de Voix Off - Vague 4

## Objectif

Ce document rassemble la quatrieme vague de scripts mot a mot pour les mini tutoriels video suivants:

1. Offres organismes
2. Partenaires & fournisseurs
3. Annuaire Entrepot
4. Comptoir

Le niveau de detail, le ton et la duree suivent la meme logique que les vagues precedentes.

---

## Regles de Lecture

- Lire avec un ton calme, clair et operationnel.
- Faire une pause courte entre deux actions visibles a l'ecran.
- Garder les noms des modules, boutons et onglets tels qu'ils apparaissent dans l'application.
- Si une action prend trop de temps pendant la capture, raccourcir au montage plutot que d'accelerer la lecture.

---

## 1. Offres organismes

### Duree cible
50 secondes

### Incrustation d'ouverture
Offres organismes
Publier une opportunite rapidement

### Script mot a mot

00:00 - 00:06
"Le module Offres organismes permet de publier rapidement des disponibilites ciblees pour les partenaires eligibles."

00:06 - 00:14
"Commencez par creer une nouvelle offre. L'objectif est de rendre visible une opportunite sans passer par une communication manuelle."

00:14 - 00:23
"Renseignez ensuite le produit, la quantite disponible, la date limite et les regles de visibilite si elles sont prevues."

00:23 - 00:32
"Avant de publier, relisez les informations affichees. Une date ou une quantite incorrecte peut generer des reservations inutiles."

00:32 - 00:42
"Publiez ensuite l'offre pour qu'elle apparaisse dans l'espace dedie des organismes concernes."

00:42 - 00:50
"Le bon reflexe est de fixer une date limite claire et de verifier la visibilite avant diffusion."

### Texte ecran recommande
- Nouvelle offre
- Produit
- Quantite
- Date limite
- Publier

### Derniere phrase a afficher
Reflexe: fixer une date limite claire avant publication.

## 2. Partenaires & fournisseurs

### Duree cible
55 secondes

### Incrustation d'ouverture
Partenaires & fournisseurs
Reutiliser la bonne fiche

### Script mot a mot

00:00 - 00:06
"Le module Partenaires et fournisseurs centralise les fiches utiles pour les achats, les entrees et le suivi des relations externes."

00:06 - 00:15
"Avant de creer une nouvelle fiche, commencez toujours par une recherche. Cela permet d'eviter les doublons dans la base."

00:15 - 00:24
"Ouvrez ensuite la fiche trouvee et verifiez les coordonnees, les categories de produits et les contacts associes."

00:24 - 00:34
"Si une mise a jour est necessaire, corrigez directement les informations utiles pour que les autres modules reutilisent une base propre."

00:34 - 00:45
"Cette fiche peut ensuite servir dans Achats pour un bon d'achat ou dans Inventaire pour une entree fournisseur."

00:45 - 00:55
"Le bon reflexe est donc simple: rechercher d'abord, corriger si besoin, puis reutiliser la fiche existante."

### Texte ecran recommande
- Recherche fiche
- Coordonnees
- Categories de produits
- Contacts
- Reutilisation dans Achats ou Inventaire

### Derniere phrase a afficher
Reflexe: rechercher avant de creer une nouvelle fiche.

Annuaire Entrepot
Retrouver un contact interne

## 4. Comptoir

### Duree cible
50 secondes

### Incrustation d'ouverture
Comptoir
Traiter une action terrain rapidement

### Script mot a mot

00:00 - 00:06
"Le module Comptoir est pense pour les interactions rapides sur site, avec une saisie simple et directe."

00:06 - 00:14
"Ouvrez une action representative, par exemple une demande, une aide ou une remise selon votre usage le plus frequent."

00:14 - 00:23
"Montrez ensuite la saisie minimale necessaire pour enregistrer l'operation sans alourdir le parcours."

00:23 - 00:33
"Validez l'action puis revenez a la vue principale pour montrer que le flux reste court et operationnel."

00:33 - 00:42
"Ce module doit toujours donner l'impression d'un passage rapide, clair et oriente terrain."

00:42 - 00:50
"Le bon reflexe est de consacrer chaque mini video Comptoir a une seule action concrete et repetitive."

### Texte ecran recommande
- Action terrain
- Saisie rapide
- Validation
- Retour a la vue principale

### Derniere phrase a afficher
Reflexe: une video Comptoir par action terrain.

---

## Conseils de Post-Production

- Garder la meme identite sonore et visuelle que pour les vagues precedentes.
- Pour Offres organismes, laisser l'ecran visible assez longtemps pour lire la date limite et la quantite.
- Pour Partenaires & fournisseurs, zoomer legerement sur la fiche pour rendre les informations lisibles.
- Pour Annuaire Entrepot, conserver un montage tres court pour rester coherent avec la promesse de rapidite.
- Pour Comptoir, privilegier un rythme vif mais lisible afin de montrer la fluidite du parcours.
