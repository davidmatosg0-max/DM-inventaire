# Scripts de Voix Off - Vague 5

## Objectif

Ce document rassemble la cinquieme vague de scripts mot a mot pour les mini tutoriels video suivants:

1. Cuisine
2. Messagerie
3. Recrutement
4. Utilisateurs/Roles

Le format, le ton et le niveau de detail restent alignes avec les vagues precedentes.

---

## Regles de Lecture

- Lire avec un ton calme, direct et professionnel.
- Faire une courte pause entre les actions visibles pour laisser le temps de lire l'ecran.
- Conserver les noms exacts des modules et des actions affiches dans l'application.
- Si un chargement ou une transition prend trop de temps, couper ce passage au montage plutot que d'accelerer la voix.

---

## 1. Cuisine

### Duree cible
55 secondes

### Incrustation d'ouverture
Cuisine
Suivre une operation principale

### Script mot a mot

00:00 - 00:06
"Le module Cuisine rassemble les ecrans utiles a la production alimentaire et au suivi des operations associees."

00:06 - 00:14
"Pour un tutoriel clair, commencez par ouvrir la vue principale du module afin de montrer le point d'entree reel de l'equipe."

00:14 - 00:24
"Montrez ensuite une operation representative, par exemple l'ouverture d'une fiche de production ou d'une vue de planification."

00:24 - 00:34
"Soulignez les zones importantes, puis validez une action concrete sans essayer de couvrir tout le module en une seule video."

00:34 - 00:45
"Revenez ensuite a la vue principale ou au departement d'origine pour montrer comment le flux se referme proprement."

00:45 - 00:55
"Le bon reflexe est de produire une video par sous-flux si le module Cuisine est utilise de maniere intensive."

### Texte ecran recommande
- Vue principale
- Fiche de production
- Planification
- Validation
- Retour a la vue principale

### Derniere phrase a afficher
Reflexe: une video courte par sous-flux cuisine.

## 4. Utilisateurs/Roles

### Duree cible
50 secondes

### Incrustation d'ouverture
Utilisateurs/Roles
Verifier ou attribuer un acces

### Script mot a mot

00:00 - 00:06
"Le module Utilisateurs et roles permet de verifier les acces et d'attribuer les bons niveaux d'autorisation."

00:06 - 00:14
"Commencez par selectionner l'utilisateur concerne pour eviter toute modification sur le mauvais profil."

00:14 - 00:23
"Montrez ensuite le role, les permissions ou les informations de profil qui influencent l'acces au systeme."

00:23 - 00:33
"Si une modification est necessaire, appliquez un changement simple puis insistez sur l'impact que cela peut avoir sur plusieurs ecrans."

00:33 - 00:42
"Enregistrez ensuite la mise a jour pour montrer un flux controle et facile a verifier."

00:42 - 00:50
"Le bon reflexe est de modifier un acces uniquement a partir d'une demande explicite et verifiee."

### Texte ecran recommande
- Selection utilisateur
- Role
- Permissions
- Enregistrer
- Acces verifie

### Derniere phrase a afficher
Reflexe: modifier un acces uniquement sur demande verifiee.

---

## Conseils de Post-Production

- Garder la meme identite sonore et le meme style visuel que pour les autres vagues.
- Pour Cuisine, ne pas chercher a tout couvrir dans la meme capsule video.
- Pour Messagerie, laisser le message affiche assez longtemps pour que la logique de lecture soit claire.
- Pour Recrutement, zoomer legerement sur les champs essentiels lors de la creation d'une fiche.
- Pour Utilisateurs/Roles, utiliser un carton discret rappelant que les changements d'acces ont un impact transversal.
