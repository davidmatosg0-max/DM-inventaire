# Scripts de Voix Off - Vague 6

## Objectif

Ce document rassemble la sixieme vague de scripts mot a mot pour les mini tutoriels video suivants:

1. Identite visuelle
2. API & integrations
3. Capsule complementaire - Verifier un reglage transversal
4. Capsule complementaire - Valider un changement d'acces

Cette vague complete la serie avec des capsules davantage orientees administration, verification et gouvernance du systeme.

---

## Regles de Lecture

- Lire avec un ton calme, precis et oriente administration.
- Marquer une courte pause entre les etapes pour laisser le temps de lire l'interface.
- Conserver les noms exacts des sections affichees a l'ecran.
- Si une verification prend du temps, couper le passage au montage plutot que d'allonger inutilement la voix off.

---

## 1. Identite visuelle

### Duree cible
40 secondes

### Incrustation d'ouverture
Identite visuelle
Adapter l'habillage du systeme

### Script mot a mot

00:00 - 00:05
"L'espace Identite visuelle permet d'ajuster rapidement l'apparence generale du systeme."

00:05 - 00:13
"Commencez par ouvrir la section de marque ou de couleur que vous souhaitez modifier."

00:13 - 00:22
"Appliquez ensuite un changement simple, par exemple une couleur ou un element d'habillage, pour garder la demonstration lisible."

00:22 - 00:31
"Montrez l'aperçu avant validation afin de verifier le rendu reel dans l'interface."

00:31 - 00:40
"Le bon reflexe est de toujours controler l'aperçu sur plusieurs ecrans avant de publier une nouvelle apparence."

### Texte ecran recommande
- Identite visuelle
- Couleur
- Aperçu
- Sauvegarder

### Derniere phrase a afficher
Reflexe: verifier l'aperçu avant toute publication.

### Incrustation d'ouverture
Administration
Verifier un reglage transversal

## 4. Capsule complementaire - Valider un changement d'acces

### Duree cible
45 secondes

### Incrustation d'ouverture
Administration
Valider un changement d'acces

### Script mot a mot

00:00 - 00:06
"Cette capsule montre comment encadrer un changement d'acces avant de l'appliquer a un utilisateur."

00:06 - 00:14
"Commencez par verifier la demande, le profil concerne et le niveau d'autorisation attendu."

00:14 - 00:23
"Ouvrez ensuite la fiche utilisateur ou la zone de roles pour montrer le point exact de controle."

00:23 - 00:32
"Expliquez qu'un acces modifie peut impacter plusieurs ecrans et qu'il faut toujours confirmer la coherence du nouveau role."

00:32 - 00:45
"Le bon reflexe est d'appliquer les droits uniquement sur demande verifiee, puis de faire une validation rapide du resultat."

### Texte ecran recommande
- Demande verifiee
- Profil utilisateur
- Role
- Validation rapide
- Acces conforme

### Derniere phrase a afficher
Reflexe: pas de changement d'acces sans verification prealable.

---

## Conseils de Post-Production

- Garder une presentation sobre et technique pour toute cette vague.
- Pour Identite visuelle, laisser apparaitre l'aperçu assez longtemps pour que le changement soit visible.
- Pour API & integrations, eviter les details de configuration sensible dans la voix ou a l'ecran.
- Pour les deux capsules complementaires, utiliser des cartons courts qui rappellent les principes de verification et de validation.
